# Roadmap

1. Validate WebGL on GPU-enabled desktop browsers and profile dense skyline views; expand the raster renderer's visibility and projection caching where needed.
2. Add intersection turning and lane changes to the existing signals and queue-spacing system, then introduce crosswalk navigation and richer pedestrian routes.
3. Add physical tumble, building fragments, particles, sound, and a more detailed hole interior.
4. Expand city seeds and introduce optional time-attack levels, mobile performance presets and real-device release testing.
5. Add persistence, a level editor, power-ups, and an optional backend leaderboard with score validation.

For larger object populations, introduce a spatial grid for capture queries and GPU instancing for static props. Keep score progression, city rules, and render assets independent.
